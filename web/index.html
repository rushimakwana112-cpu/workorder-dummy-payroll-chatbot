Knowledgebase

How the assistant reads your questions and calculates figures.
Salary month vs liable month vs payment month?

Salary month = Month + Year columns (the month the salary is for; Sep-26 salary → 9, 2026). Liable month = month_year (payment date − 1 month; paid 07-Oct-26 → 07-Sep-26). Payment date = month_year + 1 month, calculated by the chatbot (not stored in SQL). Pick the default in Settings, or say salary month, liable month or paid in oct-26.

How is base sales value and margin calculated?

Base sales value = Invoice × 100 / 118 (excl. 18% GST), counted once per work order + salary month. Margin = Base sales value − CTC. Margin % = Margin ÷ CTC × 100 (ask margin % on base sales for the sales basis). "Highest margin" answers show the top work order by amount and by margin %.

How are projections made?

Same rule as the proposed-data Excel: each running work order's CTC and base sales from the base salary month, by days it runs in the projected month (0 if it ends before that month). If the base month's data looks incomplete you get a warning and a one-click option to use the last complete month, e.g. projection of oct-26 using aug-26 data.

Can the chatbot change data?

No. Every query is a checked, read-only SELECT. Only an administrator's Refresh database button reloads the table from the source server, in one all-or-nothing transaction.

What does "AI analysis" mean?

For questions no fixed report covers, the local AI (Ollama) writes a read-only SQL query. It takes longer (up to ~1–2 minutes on this PC). Always check the SQL tab for how it was calculated.

Can I rename columns or stop commas in employee codes? (admin)

Yes — type it in chat, e.g. rename Employee column to Employee code, no commas in employee code, treat work order no as text. It applies to everyone's tables and downloads. show display rules lists them, reset display rules removes them. Only the admin, or people the admin allows (Users → Access), can change them. You can put a rule and a question in the same message.

How do I ask in SQL directly? (admin)

Start the message with /, e.g. /select Category, count(*) from Payrollall1 group by Category.
